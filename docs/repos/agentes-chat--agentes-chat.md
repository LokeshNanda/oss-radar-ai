## What it does
agentes.chat is an open-source, self-hosted alternative to Slack that integrates AI agents into team communication. It allows teams to collaborate in channels and direct messages while leveraging AI models like Claude, ChatGPT, and others to assist with tasks and decision-making.

## Why it's interesting
Unlike traditional chat applications, agentes.chat incorporates AI agents as active participants in conversations rather than passive bots. This integration allows for a more collaborative environment where agents can perform tasks, manage workflows, and interact with users in real-time, making it a unique offering in the team collaboration space.

## How it works
The application is built using TypeScript and employs a microservices architecture with Docker and PostgreSQL as its primary components. It supports various AI models and includes features like budget management for agent tasks, approval workflows for sensitive actions, and connectors to external services. The README outlines a straightforward installation process via a single command for self-hosting, but details on the internal architecture are limited, leaving some aspects of implementation uncertain.

## Get started in 5 minutes
To quickly set up agentes.chat on your own server, run the following command in your terminal:
```sh
curl -fsSL https://agentes.chat/install | sh
```
This command installs the necessary dependencies and sets up the application on your server within approximately 10 minutes.

## Watch out for
The project is licensed under AGPL-3.0, which requires any modifications to be shared publicly. Some features are still in beta, such as the agent browser and desktop applications, which may have stability issues. Additionally, while the README provides a comprehensive overview of features, it lacks detailed documentation on advanced configurations and troubleshooting, which could be a barrier for less experienced users.
