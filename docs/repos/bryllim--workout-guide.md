## What it does
The Workout Guide is an open exercise illustration library that provides 302 exercise illustrations, each with three consistent frames. It offers a framework-neutral npm package that allows developers to integrate these illustrations into their applications easily.

## Why it's interesting
Unlike typical exercise libraries, this project combines a comprehensive set of illustrations with a structured API, making it easier for developers to search and retrieve specific exercises based on criteria like equipment type. The use of SVG assets ensures high-quality visuals that are scalable and lightweight.

## How it works
The repository is structured as an npm workspace monorepo, containing a package for the API and a separate app for the gallery and documentation. It includes utilities for catalog import and validation, and all assets are checked into the repository, allowing for easy access and regeneration from source exports. The README does not specify the exact methods used for generating or normalizing the assets, leaving some uncertainty in that area.

## Get started in 5 minutes
To get started, run the following commands:
```sh
npm install
npm run check
npm run dev
```
This will set up the project locally, allowing you to explore the gallery and documentation.
