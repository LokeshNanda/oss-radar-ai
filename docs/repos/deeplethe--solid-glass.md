## What it does
Solid Glass is a design system specifically tailored for AI applications, providing a set of UI components that emphasize a refined glass-inspired aesthetic. It integrates with existing shadcn/ui components and is built using TypeScript, React, and Tailwind CSS.

## Why it's interesting
Unlike typical design systems, Solid Glass focuses on creating a calm and readable interface for dynamic AI environments, minimizing visual distractions while maintaining a sense of depth and materiality. Its unique approach balances flat design and liquid glass aesthetics, making it suitable for applications that require clarity and stability.

## How it works
The system is implemented as a single stylesheet that enhances shadcn/ui components by utilizing `data-slot` attributes and predefined classes. It includes components like `status-glyph`, `panel`, and `composer`, which are designed to facilitate interactions in AI-driven interfaces. ## Get started in 5 minutes
1. Initialize a shadcn/ui project with `npx shadcn@latest init`.
2. Add Solid Glass with `npx shadcn@latest add deeplethe/solid-glass/solid-glass`.
3. Import the stylesheet in your CSS file after Tailwind and shadcn's stylesheet.
