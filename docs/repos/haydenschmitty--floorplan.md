## What it does
Floorplan is a tool that creates an interactive map of your codebase, allowing developers to visualize how different components of their application fit together. It uses AI models like Claude or Codex to generate plain-English descriptions of code elements and their connections.

## Why it's interesting
Unlike traditional documentation tools, Floorplan provides a dynamic, visual representation of the codebase that updates as changes are made. This can significantly enhance onboarding for new team members and help developers understand the implications of code changes without deep diving into the code itself.

## How it works
Floorplan scans the codebase to identify files, imports, and web requests, then uses Claude or Codex to generate a map that illustrates these components and their relationships. It supports multiple programming languages and frameworks, including JavaScript, Python, and various web frameworks. The README does not specify how it handles edge cases or less common languages, leaving some uncertainty about its full compatibility.

## Get started in 5 minutes
1. Ensure you have Node.js 18+ installed.
2. Install the Floorplan plugin in Claude Code or Codex using the provided commands in the README.
3. Open your project in the respective tool and ask for a floorplan by typing "Make me a floorplan of this app".

The repository is relatively new (created in October 2026), which may imply that it is still maturing. The README mentions no dependencies, which is a positive aspect for security and simplicity. However, users should be cautious about the privacy implications of running AI tools on their codebases, even though the README claims that scans and maps run locally without external data transmission.
