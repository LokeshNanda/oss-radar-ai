## What it does
Abyssal Garden is an interactive 3D underwater environment that users can explore directly in their web browser. It is entirely generated by code using WebGPU, without relying on any pre-made images, models, or sound files, and is encapsulated in a single 96 KB HTML file.

## Why it's interesting
This project stands out due to its use of WebGPU for rendering complex scenes in real-time, which is not commonly seen in web applications. The entire experience is self-contained in a small file size, making it accessible and easy to share, while also showcasing the capabilities of modern web technologies.

## How it works
The application generates the underwater world dynamically using JavaScript and WebGPU, with no external libraries or game engines. The seabed and objects are created using mathematical shapes, and the sound is synthesized in real-time with the Web Audio API. The README details a structured source code layout, including files for world layout, shaders, rendering, audio, and quality settings, but does not specify the exact architecture or design patterns used.

## Get started in 5 minutes
1. Download the `index.html` file from the repository.
2. Open it in Chrome or Edge on a desktop computer.
3. Wait for the world to build, then click "Dive in" to start exploring.

## Watch out for
The application requires a browser that supports WebGPU, which may limit compatibility with some devices.
