## What it does
Free My TV is an open-source home screen launcher for Google TV, LG webOS, and Samsung Tizen that provides a fast, ad-free interface. It features a customizable app shelf, trending content from installed streaming apps, and weather information, all designed to enhance the user experience on smart TVs.

## Why it's interesting
Unlike standard TV launchers, Free My TV eliminates ads and sponsored content, focusing solely on user-selected apps and trending picks. It also allows for a high degree of customization, including the ability to use personal photos as backgrounds and to adjust settings directly from the TV.

## How it works
The application is built in Java and utilizes Claude Code for installation. It requires enabling developer mode on the TV and can be installed via an AI coding assistant or manually using ADB commands. The app pulls trending content from installed streaming services using a TMDB key, which users must obtain separately. The README provides detailed instructions for installation on different platforms (Google TV, LG webOS, Samsung Tizen) and outlines the configuration options available in a `config.properties` file.

## Get started in 5 minutes
1. Enable developer mode on your TV and note its IP address.
2. Use an AI coding assistant to say: "Install Free My TV on my TV at <your TV IP>."
3. Follow the prompts to complete the installation.

## Watch out for
The repository is relatively new, created in October 2026, which may indicate limited community support or maturity. Users need to manage their own TMDB keys for content, and there are specific installation requirements for different TV platforms. Additionally, the app may require workarounds for certain Android versions due to security features like Google Play Protect.
