## What it does
This repository provides a native Windows port of the Uncharted: The Nathan Drake Collection, allowing users to play the PS4 games Uncharted 1, 2, and 3 on Windows 10 and 11. The project translates the original game code to run on Windows using Vulkan for graphics rendering.

## Why it's interesting
Unlike traditional emulators, this project runs the original game code directly on Windows, potentially offering better performance and compatibility. It also includes advanced graphical features like anti-aliasing and frame generation, which are not typically available in standard ports or emulators.

## How it works
The application uses Vulkan for rendering and requires a decrypted dump of the PS4 game files to function. It supports various graphical enhancements such as AMD FSR and NVIDIA DLSS. The README details known issues and fixes for specific game scenarios, indicating an active development process. However, it does not provide a comprehensive architecture overview, leaving some uncertainty about the underlying implementation details.

## Get started in 5 minutes
1. Download the latest release from the [releases page](https://github.com/Supermedo/uncharted_pc/releases/latest).
2. Unpack the zip file.
3. Run `Uncharted.exe`, select your game folder containing the required PS4 files, choose a game, and press **PLAY**.

## Watch out for
The project is still in development, with known issues listed in the README, including crashes and graphical glitches. Users need to provide their own game files, as none are included. The license is GNU GPL v2 or later, which may have implications for redistribution and modification.
