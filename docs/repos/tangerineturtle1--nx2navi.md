## What it does
NX2navi is a static recompilation of *The Legend of Zelda: Ocarina of Time* for the Nintendo Switch 2, allowing it to run as a native x86-64 application on Windows with a Vulkan renderer. It requires users to provide their own legally obtained game files, which are then built into the application on their machine.

## Why it's interesting
Unlike traditional emulators, NX2navi offers a native code experience rather than emulation, which can lead to improved performance and graphical fidelity. It supports modern graphics features such as Vulkan, HDR, and various upscaling techniques, making it stand out from other methods of playing classic games.

## How it works
The application is built from user-provided game files, and it leverages Vulkan for rendering. It includes features like native widescreen support, customizable frame rates, and an in-game settings menu. The README mentions that the game is in early development and playable, with specific areas running at 60 fps or above, but also notes the presence of visual bugs and occasional crashes. The setup process involves downloading an installer that builds the game on the user's machine, which can take 10 to 25 minutes.

## Get started in 5 minutes
To get started, download `NX2navi-Setup-<version>.exe` from the releases section on GitHub and run it next to your `.nup` dump of the game. Follow the on-screen instructions to build the game on your PC.

## Watch out for
The project is in early development, so users may encounter bugs and crashes. The README warns that machines with 16 GB of RAM may run out of memory in certain areas. Additionally, the setup is not signed, which may trigger security warnings. The licensing terms restrict copying or publishing of the source's additions and changes without permission, and it is important to note that this is a non-commercial fan project not affiliated with Nintendo.
