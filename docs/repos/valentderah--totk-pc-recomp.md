## What it does
TotK Recomp is a static recompilation of *The Legend of Zelda: Tears of the Kingdom* into a native x86-64 application for Windows and Linux. It allows users to play the game on their PCs using their legally obtained game files from the Nintendo Switch.

## Why it's interesting
This project differentiates itself from traditional emulators by providing a native code experience rather than emulation, which can lead to better performance and compatibility with modern hardware. It also includes features like custom resolutions, HDR support, and modding capabilities.

## How it works
The application builds the game from the user's own files, requiring specific updates (1.1.0, 1.2.1, or 1.4.3) to be present. The setup process involves selecting game files and configuring settings through a user-friendly installer. The architecture includes a Vulkan renderer and supports various graphical enhancements. However, the README indicates that the project is in early development, with potential visual bugs and crashes expected.

## Get started in 5 minutes
1. Download `TotK-Setup-<version>-windows.zip` or `TotK-Setup-x86_64.AppImage` from the Releases section.
2. Unpack the downloaded file and run the setup executable.
3. Select your game files and desired settings, then start the installation.
4. Launch `totk.exe` or `totk` from the install folder to play.

## Watch out for
The project is in early development, meaning users may encounter bugs and crashes. Additionally, it requires a legally obtained copy of the game, and the README explicitly states that no game files are included.
