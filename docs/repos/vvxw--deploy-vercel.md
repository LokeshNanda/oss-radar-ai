## What it does
This repository provides a template for deploying a web application on Vercel, specifically tailored for users who want to create a project that utilizes a custom HTML page and environment variables. It includes instructions for setting up the project and deploying it to Vercel.

## Why it's interesting

## Get started in 5 minutes
1. Click "Use this template" to create a new repository on GitHub.
2. Modify the `index.js` file to set your environment variables.
3. Replace `index.html` with your custom HTML page.
4. Deploy the project on Vercel by importing it and setting the install command to `npm install`.
5. After deployment, verify the project and update the `DOMAIN` variable in `index.js` as needed.
